MioVRCA 1.7.10 使用说明
================================

VRChat 改模用的本地素材管理工具。把电脑里的素材、Booth 已购、百度网盘分享整理成卡片，
点卡片打开所在文件夹，点「导入」一键导入 Unity 工程。数据只保存在本机。

【安装】
  安装版：运行「MioVRCA-安装-1.7.10.exe」，不需要管理员权限。
          默认装在 C 盘以外的磁盘（例如 D:\MioVRCA），没有其他磁盘时装在 C 盘。
          软件开着的话，安装程序会问你要不要先关掉它。
          装过旧版（VRC素材库、MioVRC素材托管工具）的直接覆盖安装，数据会保留。
  便携版：解压到任意文件夹，运行 MioVRC_AssetManager.exe。

  Windows 提示「已保护你的电脑」时，点「更多信息」→「仍要运行」（程序没有付费签名）。
  界面用系统自带的 WebView2 显示；链接都用默认浏览器打开。

【第一次打开】
  选择素材文件夹（例如 D:\BaiduNetdiskDownload）和 Unity 工程文件夹（可不选），点「开始扫描」。

【常用操作】
  点卡片          打开所在文件夹（没下载的网盘素材、Booth 已购：打开详情）
  卡片上的「导入」  在详情里选工程，一键导入 Unity 工程
  右键 / 详情     改名称、分类、适配素体、标签、备注、封面，填网盘链接
  左边栏          按分类、素体、Booth / Gumroad 已购、使用情况、网盘、文件夹筛选；选「衣服」后可按风格标签筛选
                  已选中的项再点一次回到「全部」；分类、风格标签、适配素体右边的小箭头可以收起
  搜索框          名称、店铺、标签、路径、备注
  批量整理        素材数量旁边点「批量整理」，点卡片选中（按住 Shift 再点连选一片），
                  一次把它们移到别的分类、隐藏 / 取消隐藏、排除。点「完成」或按 Esc 退出。

【封面从哪来】
  自己选的 > Booth 商品图 > 素材文件夹里的图片 > 从 Unity 生成的封面 > unitypackage 里自带的预览图。
  素材文件旁边放一张同名的图片也算：「水手服.unitypackage」旁边的「水手服.png」会当作它的封面，
  名字开头相同也行（「水手服_preview.jpg」「水手服 v1.2.zip」配「水手服.png」）。
  一个文件夹里散放着好几个素材包、各自带一张同名图片时，会自动认成多个素材，每个一张卡片。
  软件只读取，不会移动或改名你的文件。
  没有封面的素材，扫描之后软件会在后台读取它的 unitypackage 里自带的预览图当封面，不需要打开 Unity。
  预览图是制作素材时 Unity 生成的，尺寸比较小；要清楚一点的，在详情里点「从 Unity 生成封面」。
  详情里可以「重新提取封面」或「移除」；「整理」→「封面」可以对整个素材库再提取一遍。

【同款合并】
  同一个商品的多个下载（不同素体的包、PSD 包）合成一张卡片。按素体筛选时只显示对应的版本。
  合错了：详情里点「取消版本合并」。

【风格标签】
  衣服按 Booth 标签和名称自动加标签（JK、Sexy、可爱、女仆……），成人向商品加「H」。
  详情里可以手动改；标签和关键词在 设置 →「风格标签」里改，格式：标签名=关键词1|关键词2。

【新素材自动整理】
  软件开着时，素材文件夹里放进新东西，下载、解压完成后会自动扫描归类，卡片标「新」。
  左边栏「动态 → 新增」可以查看。

【一键导入 Unity 工程】
  鼠标移到素材卡片上点「导入」（或打开详情），在「导入到 Unity 工程」里选工程，点「一键导入」。
  软件会先解压素材里的压缩包，包括 PSD 包、作者分开打的分卷（.zip.001、.part1.rar、.z01 等）
  和压缩包里的压缩包；有密码的在「解压密码」里填。解压完压缩包移到回收站（可以取消勾选）。
  然后把 unitypackage 里的文件直接写进工程的 Assets：工程里已有的资源（按 GUID）就地更新，
  被你挪过位置的也一样；和别的资源重名时另起名字，不会覆盖。PSD 只解压，不放进工程。
  同一个素材有不同素体的包时，按工程用的素体自动选；分不出来时会让你勾选。
  Unity 开着也可以导入，切回 Unity 就会刷新；没开就等下次打开工程。
  工程不在列表里：下拉选「选择其他工程…」。
  rar、7z 和分卷压缩包用你电脑上默认的解压软件来解（7-Zip、Bandizip、WinRAR、好压、NanaZip、
  PeaZip 都行，没设默认就用找到的那个）；普通 zip 不需要装解压软件。
  Booth「已购未下载」和网盘素材的详情里有「下载并导入」：下载、解压、导入一次完成。

【工程】
  左上角切到「工程」，每个 Unity 工程一张卡片：Unity 版本、上次打开的时间、用到素材库里的几个素材。
  「打开 Unity」用这个工程对应版本的 Unity 打开它（从 Unity Hub、VCC / ALCOM 的记录里找编辑器）；
  「文件夹」打开工程所在的文件夹；点「使用了素材库中的 N 个素材」跳到素材库里看是哪些。
  工程来自设置里的「Unity 工程文件夹」，也可以点左边的「添加工程…」。
  封面：点卡片上的「开启封面」，软件会往那个工程的 Packages 里放一个小插件（com.miovrc.projectcard）。
  之后每次打开工程、保存场景，它会给场景里的模型拍一张正面照当封面，旧的自动删掉。
  插件只在 Unity 编辑器里运行，不改场景，也不会跟模型一起上传；「关闭封面」会删掉插件和照片。
  工程里装什么插件、用哪个版本的 SDK，平时请用 VCC 或 ALCOM 管理；「新建基础工程」只在建工程时装一次常用插件。

【流水线】
  第五个页面。把导入工程的衣服、头发、配饰、道具按类别装到模型上，再生成菜单开关和图标。
  页面顶上是五个步骤：工程 → 素材 → 装配 → 菜单 → 验收，每一步的状态一眼能看到。
  在「工程」页的卡片上点「流水线」，或者导入完成的提示里点「前往流水线装配」，都会到这里。
  要用到：工程里装好 VRChat SDK 和 Modular Avatar，Unity 开着这个工程。没有工程的话先看下面的「新建基础工程」。

  1. 工程：左边选一个工程。第一次用点「安装并打开 Unity」：软件往这个工程的 Packages 里放两个编辑器插件
     （MioVRCA 改模流水线：放素体、穿戴、菜单、图标；UnitySkills：开源，让 AI 能做更多 Unity 操作，
     工程里已经有的用它自己的），然后用对应版本的 Unity 打开工程，第一次要编译一两分钟。显示「已连接」就行。
  2. 素材：工程 Assets 里导入过的素材会自动列出来，带着它在素材库里的名字和类别（素体 / 衣服 / 头发 / 配饰 / 道具）。
     勾上要装的；类别不对就在下拉里改；没列出来的位置可以手动填（Assets/店铺名/素材名）。
     Unity 连着的时候还会标出哪些「已装配」、哪些是「完整模型」。
  3. 装配 + 4. 菜单：点「运行流水线」。按类别处理：
     素体 → 场景里没有模型时，把它放进一个新场景（保存为 Assets/工程名/工程名.unity）；
     衣服 → 穿上，衣服之间互斥（参数 Clothtoggle），外套、鞋子、帽子这些做成部件开关，几个配色做成换色项；
     头发 → 戴上，头发之间单独互斥（参数 Hair_Choose），素体自带的头发也留一项，随时切回去；
     配饰 → 戴上，一个开关，默认显示；
     道具 → 装上，一个「显示」开关，默认隐藏。
     每一项都拍图标。每一步做了什么会列在下面。
  5. 验收：到 Unity 的 Play 模式里用 Gesture Manager 把菜单点一遍；满意按 Ctrl+S 保存，不满意按 Ctrl+Z 或点「撤销上一步」。

  菜单层级：默认是「主菜单 > {分类} > {素材} > {开关}」。用 > 隔开每一层；{分类} 是衣服 / 头发 / 配饰 / 道具这一层，
  {素材} 是每个素材自己的一层，{开关} 是它的开关。去掉 {素材}，每个素材就只做一个总开关。也可以用自己的话写。

  AI 服务：左边「AI 服务」点「配置」，选服务商（DeepSeek、通义千问、智谱 GLM、Kimi、ChatGPT 兼容、Claude 兼容），接口地址和默认模型会自动填好，再填 API Key，
  选模型（可以点「选择模型」），点「测试连接」确认能用，再保存。用的是你自己的 AI 账号，费用由服务商按用量收。
  Key 加密保存在这台电脑上，只发给你填的接口地址。
  不用 AI：勾「不使用 AI，按网格名称分组」，不需要 AI 账号。分得比 AI 粗，适合网格名字规范的素材。

  AI 识图：装完素材后 AI 会给模型截图（正面、背面，需要时还有侧面、脸部或只拍某一件），检查有没有穿模、错位、
  材质丢失（整块洋红色）。截图同时显示在验收记录里，点一下放大。相机自动对准模型，不改场景，也不在工程里留文件。
  · AI 模型支持识图（GPT-4o、Claude 等）：截图直接发给它。第一次截图时软件会自动检测它是否支持识图。
  · AI 模型不支持识图（例如 deepseek-v4-pro）：软件自动由同服务商的视觉模型把画面描述给它，用同一个 Key，不用设置
    （DeepSeek → deepseek-flash，智谱 → glm-4.6v-flash，通义 → qwen-vl-plus，Kimi → kimi-k3）。
    该服务商没有视觉模型（中转站、自己填的服务）时，在「AI 服务」的「识图」里另填一个（接口地址、Key、模型名称），
    由它把画面描述给 AI。「视觉模型服务商」里点智谱 GLM（glm-4.6v-flash，免费）、通义千问（qwen-vl-plus）或 Kimi（kimi-k3），
    地址和模型名就填好了；也可以自己填别家的。主模型和视觉模型是同服务商时不用再填一次 Key。
    模型名以服务商的文档为准。点「测试视觉模型」确认它读得出测试图里的数字。
  · 都没有：截图只显示在记录里，AI 会如实说明它没看到画面。
  · 「识图」里还可以选「不发送给 AI」：截图只显示在记录里，不发给任何模型。
  截图里是编辑模式下场景现在显示着的东西；菜单开关和骨骼物理的效果仍然要在 Play 模式里看。
  不用 AI 跑流水线时，最后也会截取正面和背面显示在记录里。
  UnitySkills 自带的截图操作（scene_screenshot、camera_sceneview_screenshot、camera_screenshot）AI 也能用，截图同样会交给 AI 识别。

  接着让 AI 做别的：在最下面的输入框里写要求，Ctrl+Enter 发送。例如「把鞋子开关改名叫凉鞋」
  「给外套加一个换色」「检查有没有丢失的材质」。超出穿戴和菜单的操作 AI 通过 UnitySkills 来做；
  会删除东西、保存场景、执行脚本的操作，会先停下来询问，点「仅本次允许」才执行。

  放心用：所有改动都能在 Unity 里按 Ctrl+Z 撤销；软件不会替你保存场景（放素体时新建的场景除外）。
  第一次改场景前，插件会把场景文件复制一份到 Assets/_Backup。
  「移除」会删掉软件放进工程的插件；已经穿好的素材和菜单都留着，它们只依赖 Modular Avatar。

【新建基础工程】
  在「流水线」页左边点「新建基础工程…」：填工程名称，选保存位置（默认是 ALCOM / VCC 的工程文件夹），
  要的话选一个素材库里的素体，勾上要装的插件，点「创建」。软件会：
  建好 Unity 2022.3.22f1 的 VRChat 头像工程（工程设置来自 VRChat 官方模板）；
  从各插件的官方仓库下载最新稳定版装进去：VRChat SDK（Avatars）、Modular Avatar、lilToon、Avatar Optimizer、
  Gesture Manager、VRCFury（可勾选，Av3Emulator 可选）；ALCOM / VCC 已经下载过的直接复用；
  把选的素体导入工程；装上 Unity 插件并打开 Unity（可勾选）；把工程加进 ALCOM / VCC 的工程列表。
  建好后点「前往流水线」，勾上素体运行流水线，它会把素体放进场景。
  左边「运行环境」会显示有没有 Unity 2022.3.22f1、ALCOM、VCC；没装 Unity 的可以点「安装」用 Unity Hub 装。

【百度网盘】
  详情里填分享链接（可以直接粘贴整段分享文字）。只在网盘里的素材：右上角「网盘素材」。
  文件夹名里有 Booth 商品编号的会直接对上商品；合集分享会按分类文件夹拆成多张卡片。
  拆错了：在分享的详情里点「合并显示」。

【百度网盘下载】
  网盘素材的详情里点「下载」，第一次会在软件里打开百度的登录页，登录后自动开始。
  登录状态加密保存在本机，不用每次登录；设置 →「百度网盘」可以更换账号或退出登录。
  下载时先把分享存到你网盘的「MioVRCA」文件夹，再下载到下载位置，压缩包自动解压，
  下完自动入库，网盘卡片换成本地素材卡片。网盘里那份副本不会自动删除，不需要可以自己删。
  只要其中一部分：在详情的「网盘内容」里勾选要的文件或文件夹，点「下载所选」。只转存、
  下载勾选的部分，文件夹结构不变。下好的素材详情里还留着这份列表（下过的标「已下载」），
  以后可以再勾别的接着下，会放进同一个文件夹。
  下载中断了再点一次「下载」，会接着下完。
  百度有时要求先输入验证码才能打开分享：软件会弹出验证码图片，输入后自动接着下载，看不清可以换一张；
  这时点「稍后输入」，之后可在底部状态栏或素材详情里点「输入」。同一个分享验证过一次，重新下载不再重复验证。
  速度由百度决定：普通账号会被限速，开通百度网盘超级会员后会快很多；软件不能绕过限速。
  添加网盘素材时勾「添加后立即下载到素材库」，收录和下载一步完成。

【从我的百度网盘下载】
  分享打不开、或反复要求验证码时，可以先在百度网盘客户端或网页里把分享「保存到网盘」，
  再点「+ 网盘素材」→「从我的百度网盘下载」，在自己的网盘里选文件夹或文件下载到素材库。
  同样自动解压、入库，合集包自动拆分；不会转存，也不会改动网盘里的文件。

【Google Drive / Dropbox】
  「网盘素材」里也可以粘贴 Google Drive 或 Dropbox 的公开分享链接，不需要登录，也不用提取码。
  Google Drive 的文件夹会列出里面的文件，可以勾选一部分下载；Dropbox 的文件夹按一个 zip 下载。
  下载、解压、入库和百度网盘一样。需要登录或密码才能打开的分享不支持；访问 Google Drive 可能需要代理。

【合集包】
  有的网盘分享是一个总压缩包，里面是很多素材各自的压缩包（有时先按衣服、头发分了类，再装各个素材）。
  下载解压后，软件会自动把它拆开，每个素材一张卡片，分类按所在的文件夹来；同一个素材的多素体版本包、
  PSD 包不会被拆开。「下载并导入」遇到合集只拆分，不导入。
  没拆开的合集（关了自动解压的、以前下载的、自己放进素材文件夹的）卡片上会标「合集 · N」，不能一键导入，
  否则里面所有素材会一次导进工程。详情的「导入到 Unity 工程」里点「拆分为 N 个素材」（需要时会先解压）；
  如果它其实就是一个素材，点「作为单个素材」，之后照常一键导入。
  rar、7z 的合集，还有里面的压缩包只按分类或编号起名的合集，要解压后才认得出来：一键导入时
  软件解压后发现是合集，会改成拆分，不导入。
  「识别调整」里的「拆分为多个素材」也会一次拆到底。拆错了：设置 →「手动调整」里点「恢复」。

【作者更新】
  网盘分享每天、Booth 商品页每周检查一次变化；Booth 下载页有更新版本时也会提示。
  卡片上会出现更新图标，左边栏「动态 → 有更新」可以查看。设置里可以关闭。

【Booth 已购】
  左边栏「同步 Booth 已购」，软件会在 Booth 页打开登录页面，登录后自动读取。
  登录只保存在本机，不读取你平时用的浏览器。

【下载 Booth 已购】
  左边栏「已购未下载」里的卡片点「下载」，或在详情里一个文件一个文件下载；
  上面的「全部下载」会下载列表里所有商品。
  文件下载到「商品编号 商品名」文件夹，压缩包自动解压（包括里面的 PSD 包和分卷），下完自动入库。
  下载位置、是否解压、是否保留压缩包在 设置 →「下载位置」里改。没改过的话，Booth 和网盘的下载
  都放在 C 盘以外剩余空间最大的那个盘的 MioVRCdownload 文件夹（优先选素材文件夹所在的盘；
  只有 C 盘时放在第一个素材文件夹里）。
  在软件里的 Booth 已购页面点「下载」，也会进软件的下载。
  用的是软件里的 Booth 登录。登录过期时会先在后台确认一次，不行的话底部会提示「登录」，
  点一下重新登录即可，下载会接着进行。

【Gumroad 已购】
  左边栏「Gumroad 已购」点「登录」，软件里会打开 Gumroad 的登录页，登录后自动读取已购
  （包括已归档的）。以后点「重新同步」读新买的。
  没下载的显示成卡片，在「已购未下载」里。点「下载」，或在详情里一个文件一个文件下载，
  「全部下载」也会一起下。文件下载到「商品名」文件夹，解压、入库和 Booth 一样，下载位置也是同一个。
  会员订阅停了、租期到了、只能在线看的商品没有可下载的文件，详情里会写原因，
  点「下载页」到 Gumroad 上看。
  登录状态加密保存在本机，只用于访问 gumroad.com。设置 →「Gumroad 已购」可以退出登录、清空记录；
  退出登录不会删掉已经读到的已购和已经下载的文件。
  登录失效时下载会停下来并提示重新登录：左边栏「Gumroad 已购」点「登录」，登录后再点下载。

【Booth 页】
  左上角切到「Booth」，点选分类（衣服、头发、皮肤……）、适配素体、风格标签找素材，都可以多选。
  多个分类是「或」，素体、风格、搜索框里的词是「且」。风格选「H」或勾「包含成人向内容」会显示成人向商品。
  卡片会标出「已购」「素材库已有」；勾「隐藏已购商品」「隐藏素材库已有」可以只看没有的。
  点卡片看图片和说明，已购的可以直接下载；点「在 Booth 中打开」在软件里打开商品页，可以直接购买。
  左上角「我的 Booth」有登录、已购列表、购物车、同步已购。右上角可以按人气、最新上架、价格排序。
  素材卡片上的 Booth 按钮会跳到这里。页面上方的按钮：后退、前进、刷新、复制链接、在浏览器打开、返回。

【闲鱼】
  左上角切到「闲鱼」，在搜索框输入关键词，按回车搜索。
  从 1.7.7 起，闲鱼页面不再用软件的内置浏览器（Booth、网盘等页面仍然用它），有两种打开方式，第一次进入时选择：
    在软件内打开：用一个独立的内嵌浏览器。软件不往页面里放脚本、不读写 Cookie、不走设置里的代理，也不保存登录，
                  通常每次启动软件后要重新扫码登录。登录、聊天、下单都可以在里面完成。
                  页面里在新标签页打开的链接（比如商品详情）会显示成单独的窗口。
    在默认浏览器中打开：闲鱼交给系统的默认浏览器，和平时用浏览器一样。
                  没有 WebView2 的电脑，或者以管理员身份运行软件时，只有这一种方式。
  之后可以在「闲鱼」页左侧的「打开方式」里更改。
  此前有用户在内置浏览器里登录闲鱼后账号被平台限制。独立的内嵌浏览器去掉了可能引起这个问题的因素，
  但仍可能被网站认出是应用内的浏览器，软件不能保证不触发平台的风控；账号比较重要时，建议用默认浏览器。
  收录网盘分享：卖家发来网盘分享后，复制整段分享文字（链接和提取码），页面上方会出现「收录」提示；
  也可以复制后点「收录网盘链接」。软件不读取闲鱼页面里的任何内容（剪贴板的说明见下面的「复制链接提示」）。
  能收录的是百度网盘、Google Drive、Dropbox 的分享；其他网盘（夸克、阿里云盘等）的分享不会提示，
  点「收录网盘链接」时会说明暂不支持。
  「闲鱼」页不再记住上次打开的页面，每次启动从首页开始。
  Booth、百度网盘等内置页面的登录仍会长期保留，重启、更新软件后不用重新登录；网站自己让登录过期时才需要再登录。

【复制链接提示】
  在别的程序里（浏览器、聊天软件）复制了闲鱼、Booth 或网盘分享的链接，切回软件后，不管在哪个页面，
  顶部都会出现一条提示：闲鱼、Booth 的链接点「打开」，在软件里对应的页面打开；网盘分享点「收录」；不需要就点「忽略」。
  只认这三类链接：普通的淘宝商品链接不会提示，软件自己「复制链接」复制出来的也不会。
  闲鱼选了「在默认浏览器中打开」时闲鱼链接不提示；没有内置浏览器的电脑上 Booth 链接不提示。
  软件只在自己位于前台时查看剪贴板：网盘分享把复制的那段文字交给界面，闲鱼和 Booth 只取链接本身，
  别的内容不传给界面、不保存、不记录；密码管理器这类标记为不供读取的内容不读取。
  不想要：设置 →「自动化」里取消「复制闲鱼、Booth、网盘链接后提示打开或收录」，
  或者在「闲鱼」页左侧取消「复制链接后提示打开或收录」。

【上传前体检】
  流水线页「验收」里点「上传前体检」（运行流水线后会自动做一次），Unity 要开着并装好 Unity 插件。
  会列出会导致上传失败的问题（同步参数超过 256 位、PhysBone 超过 256 个、丢失的脚本、菜单一页超过 8 项）、
  粉色或缺失的材质、4096 像素以上的贴图，以及三角面、材质槽、骨骼等各项参数和 VRChat SDK 的性能评级。
  这些是构建前的数值，上传时 Modular Avatar、AAO、VRCFury 还会改动模型。
  工程页的卡片上会显示评级，点「详情」能看到上次体检的各项参数，也可以重新体检。
  能一键处理的三项旁边有按钮：「贴图降到 2048」只改贴图的导入设置（Max Size），处理后可以点「恢复」改回原设置；
  「移除灯光」「移除丢失的脚本」改的是场景，可以在 Unity 里按 Ctrl+Z 或点「撤销上一步」撤销。处理完会自动重新体检。
  脚本丢失如果是因为插件（Modular Avatar、VRCFury 等）没装或编译出错，先装好或修好插件，不要移除：移除并保存场景后，这些组件上的设置找不回来。
  「导出报告图片」把评级和主要数值画成一张图，可以复制到群聊或保存。

【装配方案】
  流水线跑完后点「保存为方案」，把装了哪些素材、菜单怎么排记下来。
  在流水线页点「装配方案」，可以把方案应用到别的工程或别的素体（先预览，再应用，不经过 AI），也可以导出成文件发给朋友、导入别人的方案。
  方案里不含素材文件；导入时会列出需要的素材和商品链接。

【素材更新】
  已购或网盘里的素材有了新文件，卡片上会标「有更新」，左侧「动态」里可以筛选。
  详情里点「下载新版」只下载；点「下载并更新到工程」会依次下载、解压并导入勾选的工程，旧版本默认保留。
  Booth 商品页改了名称、价格、说明的，标的是「有变更」。

【整理】
  素材库上方的「整理」：找重复文件、内容已经解压过的压缩包，看各文件夹和分类占了多少空间，看每个素体有多少可用的素材。
  要清理的文件只会移到回收站，移动前会逐一列出并要求确认；没有回收站的磁盘（移动硬盘、U 盘）不会动。

【迁移到另一台电脑】
  设置里「导出素材库…」把素材库数据打成一个 zip（不含素材文件本身；登录状态、API Key、AI 服务地址、代理、下载位置和体检记录也不导出）。
  在另一台电脑上「导入素材库…」，为每个素材文件夹指定本机的位置，选合并或替换。导入前会自动备份，可以撤销。

【愿望单】
  Booth 页的搜索结果和商品详情里可以「加入愿望单」，也可以粘贴商品链接加入。
  每天检查一次价格，降价时提醒；列表里能看到各款式的价格、价格记录和历史最低价。买了之后会自动标成已购。

【关注的店铺】
  Booth 页左侧的「关注的店铺」：在店铺或商品页点「关注店铺」，也可以粘贴店铺链接或商品链接。
  每天查看一次店铺的商品列表，有新商品时提醒；可以对单个店铺关闭检查，或取消关注。

【Jinxxy】
  「闲鱼」标签页上方可以切到 Jinxxy，在软件里浏览、登录、购买。搜索借用必应的站内搜索。
  在 Jinxxy 页面里下载的文件会自动存到下载文件夹并收进素材库。

【Avatar Explorer / KonoAsset】
  素材文件夹里有 Avatar Explorer 或 KonoAsset 的话，扫描时它们的数据库、备份和图片不会当成素材，同一文件夹里的其他素材照常收录。
  设置里「Avatar Explorer → 导入素材信息…」「KonoAsset → 导入素材信息…」可以把它们记录的 Booth 商品、分类、
  适配素体、标签、备注、封面补进来，只填这里还没设置的内容，不会改动它们自己的数据。

【语言】
  设置最上面可以切换 简体中文 / English / 日本語。AI 的回复、流水线写进模型菜单的名称也跟着界面语言。
  更新日志只有中文。

【识别不对】
  分类、名称、适配素体认错了：详情的「素材信息」里改，改过的以手动修改为准；很多个一起改用「批量整理」。
  一个文件夹里其实是好几个素材，却并成了一张卡片：详情最下面点「拆分为多个素材」。
  不是素材的文件夹：详情最下面点「隐藏」或「排除」（扫描时跳过）。都可以在设置的「手动调整」里恢复。
  适配素体除了看文件名，还会读 Booth 商品页的标题、标签和说明里「対応アバター」那一段。

【更新】
  有新版本时右上角会出现提示，点「更新并重启」即可，数据不受影响。
  右下角的版本号可以打开更新日志。更新后第一次打开会显示这一版改了什么。

【反馈】
  右下角「反馈与建议」，内容会发到作者邮箱。

【数据位置】
  安装版：%LOCALAPPDATA%\MioVRC_AssetManager（从旧版升级的仍在 %LOCALAPPDATA%\VRC素材库）
  便携版：程序所在文件夹
  卸载时会询问是否删除数据。

【已知限制】
  rar / 7z 里的内容不参与工程使用分析和 PSD 统计
  网盘分享在下载之前只能读到文件名和大小
  百度网盘下载用的是网页版的接口，百度改版后可能需要更新软件
  没有 WebView2 的电脑上，Booth 等内置页面会开在单独的 Edge / Chrome 窗口里，闲鱼页面在默认浏览器中打开
  AI 识图要把模型的截图发给所选的 AI 服务（或视觉模型）；不想发就在「识图」里选「不发送给 AI」
  视觉模型的描述可能看漏或看错，穿模这类细节以截图和 Unity 里的实际效果为准
  流水线用 AI 时效果取决于你选的模型：要选支持工具调用（function calling）的对话模型，能力弱的模型容易分错部件
  流水线的穿戴和菜单需要工程里有 Modular Avatar（1.12 以上）；不是给当前素体做的衣服，骨架可能对不上
  新建基础工程要能连上 GitHub 和各插件的仓库；下载不了的插件会跳过并提示，可以之后在 ALCOM / VCC 里补装
  只支持 Windows 10 / 11（64 位）
