MioVRCA 1.7.3 使用说明
================================

VRChat 改模用的本地素材管理工具。把电脑里的素材、Booth 已购、百度网盘分享整理成卡片，
点卡片打开所在文件夹，点「导入」一键导入 Unity 工程。数据只保存在本机。

【安装】
  安装版：运行「MioVRCA-安装-1.7.3.exe」，不需要管理员权限。
          默认装在 C 盘以外的磁盘（例如 D:\MioVRCA），没有其他磁盘时装在 C 盘。
          软件开着的话，安装程序会问你要不要先关掉它。
          装过旧版（VRC素材库、MioVRC素材托管工具）的直接覆盖安装，数据会保留。
  便携版：解压到任意文件夹，运行 MioVRC_AssetManager.exe。

  Windows 提示「已保护你的电脑」时，点「更多信息」→「仍要运行」（程序没有付费签名）。
  界面用系统自带的 WebView2 显示；链接都用默认浏览器打开。

【第一次打开】
  选择素材文件夹（例如 D:\BaiduNetdiskDownload）和 Unity 工程文件夹（可不选），点「开始扫描」。

【常用操作】
  点卡片          打开所在文件夹（没下载的网盘素材、Booth 已购：打开详情）
  卡片上的「导入」  在详情里选工程，一键导入 Unity 工程
  右键 / 详情     改名称、分类、适配素体、标签、备注、封面，填网盘链接
  左边栏          按分类、素体、Booth / Gumroad 已购、工程使用、网盘、文件夹筛选；选「衣服」后可按风格标签筛选
                  已选中的项再点一次回到「全部」；分类、风格标签、适配素体右边的小箭头可以收起
  搜索框          名称、店铺、标签、路径、备注
  批量整理        素材数量旁边点「批量整理」，点卡片选中（按住 Shift 再点连选一片），
                  一次把它们移到别的分类、隐藏 / 取消隐藏、不再收录。点「完成」或按 Esc 退出。

【封面从哪来】
  自己选的 > Booth 商品图 > 素材文件夹里的图片。
  素材文件旁边放一张同名的图片也算：「水手服.unitypackage」旁边的「水手服.png」会当作它的封面，
  名字开头相同也行（「水手服_preview.jpg」「水手服 v1.2.zip」配「水手服.png」）。
  一个文件夹里散放着好几个素材包、各自带一张同名图片时，会自动认成多个素材，每个一张卡片。
  软件只读取，不会移动或改名你的文件。

【同款合并】
  同一个商品的多个下载（不同素体的包、PSD 包）合成一张卡片。按素体筛选时只显示对应的版本。
  合错了：详情里点「不和同款合并」。

【风格标签】
  衣服按 Booth 标签和名称自动加标签（JK、Sexy、可爱、女仆……），成人向商品加「H」。
  详情里可以手动改；标签和关键词在 设置 →「风格标签」里改，格式：标签名=关键词1|关键词2。

【新素材自动整理】
  软件开着时，素材文件夹里放进新东西，下载、解压完成后会自动扫描归类，卡片标「新」。
  左边栏「动态 → 新加入」可以查看。

【一键导入 Unity 工程】
  鼠标移到素材卡片上点「导入」（或打开详情），在「导入 Unity 工程」里选工程，点「一键导入」。
  软件会先解压素材里的压缩包，包括 PSD 包、作者分开打的分卷（.zip.001、.part1.rar、.z01 等）
  和压缩包里的压缩包；有密码的在「解压密码」里填。解压完压缩包移到回收站（可以取消勾选）。
  然后把 unitypackage 里的文件直接写进工程的 Assets：工程里已有的资源（按 GUID）就地更新，
  被你挪过位置的也一样；和别的资源重名时另起名字，不会覆盖。PSD 只解压，不放进工程。
  同一个素材有不同素体的包时，按工程用的素体自动选；分不出来时会让你勾选。
  Unity 开着也可以导入，切回 Unity 就会刷新；没开就等下次打开工程。
  工程不在列表里：下拉选「选择其他工程…」。
  rar、7z 和分卷压缩包用你电脑上默认的解压软件来解（7-Zip、Bandizip、WinRAR、好压、NanaZip、
  PeaZip 都行，没设默认就用找到的那个）；普通 zip 不需要装解压软件。
  Booth「已购未下载」和网盘素材的详情里有「下载并导入」：下载、解压、导入一次完成。

【工程】
  左上角切到「工程」，每个 Unity 工程一张卡片：Unity 版本、上次打开的时间、用到素材库里的几个素材。
  「打开 Unity」用这个工程对应版本的 Unity 打开它（从 Unity Hub、VCC / ALCOM 的记录里找编辑器）；
  「文件夹」打开工程所在的文件夹；点「用到 N 个素材」跳到素材库里看是哪些。
  工程来自设置里的「Unity 工程」文件夹，也可以点左边的「添加工程…」。
  封面：点卡片上的「开启封面」，软件会往那个工程的 Packages 里放一个小插件（com.miovrc.projectcard）。
  之后每次打开工程、保存场景，它会给场景里的模型拍一张正面照当封面，旧的自动删掉。
  插件只在 Unity 编辑器里运行，不改场景，也不会跟模型一起上传；「关闭封面」会删掉插件和照片。
  工程里装什么插件、用哪个版本的 SDK，平时请用 VCC 或 ALCOM 管理；「新建基础工程」只在建工程时装一次常用插件。

【流水线】
  第五个页面。把导入工程的衣服、头发、配饰、道具按类别装到模型上，再生成菜单开关和图标。
  页面顶上是五个工位：工程 → 素材 → 装配 → 菜单 → 验收，每一站的状态一眼能看到。
  在「工程」页的卡片上点「流水线」，或者导入完成的提示里点「去流水线装上它」，都会到这里。
  要用到：工程里装好 VRChat SDK 和 Modular Avatar，Unity 开着这个工程。没有工程的话先看下面的「新建基础工程」。

  1. 工程：左边选一个工程。第一次用点「安装并打开 Unity」：软件往这个工程的 Packages 里放两个编辑器插件
     （MioVRCA 改模流水线：放素体、穿戴、菜单、图标；UnitySkills：开源，让 AI 能做更多 Unity 操作，
     工程里已经有的用它自己的），然后用对应版本的 Unity 打开工程，第一次要编译一两分钟。显示「已连接」就行。
  2. 素材：工程 Assets 里导入过的素材会自动列出来，带着它在素材库里的名字和类别（素体 / 衣服 / 头发 / 配饰 / 道具）。
     勾上要装的；类别不对就在下拉里改；没列出来的位置可以手动填（Assets/店铺名/素材名）。
     Unity 连着的时候还会标出哪些已经在模型上、哪些是整只模型。
  3. 装配 + 4. 菜单：点「开始流水线」。按类别处理：
     素体 → 场景里没有模型时，把它放进一个新场景（保存为 Assets/工程名/工程名.unity）；
     衣服 → 穿上，衣服之间互斥（参数 Clothtoggle），外套、鞋子、帽子这些做成部件开关，几个配色做成换色项；
     头发 → 戴上，头发之间单独互斥（参数 Hair_Choose），素体自带的头发也留一项，随时切回去；
     配饰 → 戴上，一个开关，默认显示；
     道具 → 装上，一个「显示」开关，默认隐藏。
     每一项都拍图标。每一步做了什么会列在下面。
  5. 验收：到 Unity 的 Play 模式里用 Gesture Manager 把菜单点一遍；满意按 Ctrl+S 保存，不满意按 Ctrl+Z 或点「撤销上一步」。

  菜单层级：默认是「主菜单 > {分类} > {素材} > {开关}」。用 > 隔开每一层；{分类} 是衣服 / 头发 / 配饰 / 道具这一层，
  {素材} 是每个素材自己的一层，{开关} 是它的开关。去掉 {素材}，每个素材就只做一个总开关。也可以用自己的话写。

  AI 服务：左边「AI 服务」点「设置」，选服务商（DeepSeek、通义千问、智谱 GLM、Kimi、ChatGPT 兼容、Claude 兼容），接口地址和默认模型会自动填好，再填 API Key，
  选模型（可以点「选择模型」），点「测试连接」确认能用，再保存。用的是你自己的 AI 账号，费用由服务商按用量收。
  Key 加密保存在这台电脑上，只发给你填的接口地址。
  不用 AI：勾「不用 AI，按网格名字分组」，不需要 AI 账号。分得比 AI 粗，适合网格名字规范的素材。

  AI 看图：装完素材后 AI 会给头像拍照（正面、背面，需要时还有侧面、脸部或只拍某一件），检查有没有穿模、错位、
  材质丢失（整块洋红色）。截图同时显示在验收记录里，点一下放大。相机自动对准头像，不改场景，也不在工程里留文件。
  · 模型自己能看图（GPT-4o、Claude 等）：截图直接发给它。第一次拍照时软件会自动测一次它能不能看图。
  · 模型看不了图（例如 deepseek-v4-pro）：软件自动请同一家的看图模型把画面描述给它，用同一个 Key，不用设置
    （DeepSeek → deepseek-flash，智谱 → glm-4.6v-flash，通义 → qwen-vl-plus，Kimi → kimi-k3）。
    这一家没有看图模型（中转站、自己填的服务）时，在「AI 服务」设置的「看图」里另填一个（接口地址、Key、模型名），
    由它把画面描述给 AI。「看图模型用哪家」里点智谱 GLM（glm-4.6v-flash，免费）、通义千问（qwen-vl-plus）或 Kimi（kimi-k3），
    地址和模型名就填好了；也可以自己填别家的。主模型和看图模型是同一家时不用再填一次 Key。
    模型名以服务商的文档为准。点「测试看图模型」确认它读得出测试图里的数字。
  · 都没有：截图只显示给你看，AI 会如实说它没看到画面。
  · 「看图」里还可以选「不给 AI 看」：截图只显示在记录里，不发给任何模型。
  截图里是编辑模式下场景现在显示着的东西；菜单开关和骨骼物理的效果仍然要在 Play 模式里看。
  不用 AI 跑流水线时，最后也会拍正面和背面给你看。
  UnitySkills 自带的截图操作（scene_screenshot、camera_sceneview_screenshot、camera_screenshot）AI 也能用，图同样会交给它看。

  接着让 AI 做别的：在最下面的输入框里写要求，Ctrl+Enter 发送。例如「把鞋子开关改名叫凉鞋」
  「给外套加一个换色」「检查有没有丢失的材质」。超出穿戴和菜单的操作 AI 通过 UnitySkills 来做；
  会删除东西、保存场景、执行脚本的操作，会先停下来问你，点「允许这一次」才执行。

  放心用：所有改动都能在 Unity 里按 Ctrl+Z 撤销；软件不会替你保存场景（放素体时新建的场景除外）。
  第一次改场景前，插件会把场景文件复制一份到 Assets/_Backup。
  「移除」会删掉软件放进工程的插件；已经穿好的素材和菜单都留着，它们只依赖 Modular Avatar。

【新建基础工程】
  在「流水线」页左边点「新建基础工程…」：起个名字，选放在哪个文件夹（默认是 ALCOM / VCC 的工程文件夹），
  要的话选一个素材库里的素体，勾上要装的插件，点「创建」。软件会：
  建好 Unity 2022.3.22f1 的 VRChat 头像工程（工程设置来自 VRChat 官方模板）；
  从各插件的官方仓库下载最新稳定版装进去：VRChat SDK（Avatars）、Modular Avatar、lilToon、Avatar Optimizer、
  Gesture Manager、VRCFury（可勾选，Av3Emulator 可选）；ALCOM / VCC 已经下载过的直接复用；
  把选的素体导入工程；装上 AI 插件并打开 Unity（可勾选）；把工程加进 ALCOM / VCC 的工程列表。
  建好后点「去流水线」，勾上素体开始流水线，它会把素体放进场景。
  左边「这台电脑」会显示有没有 Unity 2022.3.22f1、ALCOM、VCC；没装 Unity 的可以点「安装」用 Unity Hub 装。

【百度网盘】
  详情里填分享链接（可以直接粘贴整段分享文字）。只在网盘里的素材：右上角「网盘素材」。
  文件夹名里有 Booth 商品编号的会直接对上商品；合集分享会按分类文件夹拆成多张卡片。
  拆错了：在分享的详情里点「合并显示」。

【百度网盘下载】
  网盘素材的详情里点「下载」，第一次会在软件里打开百度的登录页，登录后自动开始。
  登录信息加密保存在这台电脑上，不用每次登录；设置 →「百度网盘」可以更换账号或退出。
  下载时先把分享存到你网盘的「MioVRCA」文件夹，再下载到下载位置，压缩包自动解压，
  下完自动入库，网盘卡片换成本地素材卡片。网盘里那份副本不会自动删除，不需要可以自己删。
  只要其中一部分：在详情的「网盘内容」里勾选要的文件或文件夹，点「下载所选」。只转存、
  下载勾选的部分，文件夹结构不变。下好的素材详情里还留着这份列表（下过的标「已下载」），
  以后可以再勾别的接着下，会放进同一个文件夹。
  下载中断了再点一次「下载」，会接着下完。
  速度由百度决定：普通账号会被限速，开通百度网盘超级会员后会快很多；软件不能绕过限速。
  添加网盘素材时勾「添加后直接下载到素材库」，收录和下载一步完成。

【作者更新】
  网盘分享每天、Booth 商品页每周检查一次变化；Booth 下载页有更新版本时也会提示。
  卡片上会出现更新图标，左边栏「动态 → 有更新」可以查看。设置里可以关闭。

【Booth 已购】
  左边栏「同步 Booth 已购」，软件会在 Booth 页打开登录页面，登录后自动读取。
  登录只保存在本机，不读取你平时用的浏览器。

【下载 Booth 已购】
  左边栏「已购未下载」里的卡片点「下载」，或在详情里一个文件一个文件下载；
  上面的「全部下载」会下载列表里所有商品。
  文件下载到「商品编号 商品名」文件夹，压缩包自动解压（包括里面的 PSD 包和分卷），下完自动入库。
  下载位置、是否解压、是否保留压缩包在 设置 →「下载位置」里改。没改过的话，Booth 和网盘的下载
  都放在 C 盘以外剩余空间最大的那个盘的 MioVRCdownload 文件夹（优先选素材文件夹所在的盘；
  只有 C 盘时放在第一个素材文件夹里）。
  在软件里的 Booth 已购页面点「下载」，也会进软件的下载。
  用的是软件里的 Booth 登录。登录过期时会先在后台确认一次，不行的话底部会提示「登录」，
  点一下重新登录即可，下载会接着进行。

【Gumroad 已购】
  左边栏「Gumroad 已购」点「登录」，软件里会打开 Gumroad 的登录页，登录后自动读取已购
  （包括已归档的）。以后点「重新同步」读新买的。
  没下载的显示成卡片，在「已购未下载」里。点「下载」，或在详情里一个文件一个文件下载，
  「全部下载」也会一起下。文件下载到「商品名」文件夹，解压、入库和 Booth 一样，下载位置也是同一个。
  会员订阅停了、租期到了、只能在线看的商品没有可下载的文件，详情里会写原因，
  点「下载页」到 Gumroad 上看。
  登录加密保存在这台电脑上，只发给 gumroad.com。设置 →「Gumroad 已购」可以退出登录、清空记录；
  退出登录不会删掉已经读到的已购和已经下载的文件。
  登录失效时下载会停下来并提示重新登录：左边栏「Gumroad 已购」点「登录」，登录后再点下载。

【Booth 页】
  左上角切到「Booth」，点选分类（衣服、头发、皮肤……）、适配素体、风格标签找素材，都可以多选。
  多个分类是「或」，素体、风格、搜索框里的词是「且」。风格选「H」或勾「包含成人向」会显示成人向商品。
  卡片会标出「已购」「素材库已有」；勾「不显示已购」「不显示素材库里有的」可以只看没有的。
  点卡片看图片和说明，已购的可以直接下载；点「在 Booth 打开」在软件里打开商品页，可以直接购买。
  左上角「我的 Booth」有登录、已购列表、购物车、同步已购。右上角可以按人气、新上架、价格排序。
  素材卡片上的 Booth 按钮会跳到这里。页面上方的按钮：后退、前进、刷新、复制链接、在浏览器打开、返回。

【闲鱼】
  左上角切到「闲鱼」，在搜索框输入关键词，按回车搜索。登录、聊天、下单都在软件里完成，登录保存在本机。
  登录会长期保留，重启、更新软件后不用重新登录（闲鱼、Booth、百度网盘都一样）；网站自己让登录过期时才需要再登录。
  卖家发来网盘分享后，在聊天里选中整段分享文字（链接和提取码），点上方「收录网盘链接」即可收进素材库。

【识别不对】
  分类、名称、适配素体认错了：详情的「整理」里改，改过的以你的为准；很多个一起改用「批量整理」。
  一个文件夹里其实是好几个素材，却并成了一张卡片：详情最下面点「拆成多个素材」。
  不是素材的文件夹：详情最下面点「隐藏」或「不再收录」（扫描时跳过）。都可以在设置的「手动调整」里撤销。
  适配素体除了看文件名，还会读 Booth 商品页的标题、标签和说明里「対応アバター」那一段。

【更新】
  有新版本时右上角会出现提示，点「更新并重启」即可，数据不受影响。
  右下角的版本号可以打开更新公告。更新后第一次打开会显示这一版改了什么。

【反馈】
  右下角「反馈和建议」，内容会发到作者邮箱。

【数据位置】
  安装版：%LOCALAPPDATA%\MioVRC_AssetManager（从旧版升级的仍在 %LOCALAPPDATA%\VRC素材库）
  便携版：程序所在文件夹
  卸载时会询问是否删除数据。

【已知限制】
  rar / 7z 里的内容不参与工程使用分析和 PSD 统计
  网盘分享在下载之前只能读到文件名和大小
  百度网盘下载用的是网页版的接口，百度改版后可能需要更新软件
  没有 WebView2 的电脑上，Booth 和闲鱼页面会开在单独的 Edge / Chrome 窗口里
  AI 看图要把头像的截图发给你选的 AI 服务（或看图模型）；不想发就在「看图」里选「不给 AI 看」
  看图模型的描述可能看漏或看错，穿模这类细节以你自己看截图、在 Unity 里看为准
  流水线用 AI 时效果取决于你选的模型：要选支持工具调用（function calling）的对话模型，能力弱的模型容易分错部件
  流水线的穿戴和菜单需要工程里有 Modular Avatar（1.12 以上）；不是给当前素体做的衣服，骨架可能对不上
  新建基础工程要能连上 GitHub 和各插件的仓库；下载不了的插件会跳过并提示，可以之后在 ALCOM / VCC 里补装
  只支持 Windows 10 / 11（64 位）
