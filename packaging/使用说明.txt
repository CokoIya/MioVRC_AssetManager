VRC素材库 1.2 使用说明
======================

一个给 VRChat 改模用的本地素材管理器：把电脑里散落的素材（百度网盘下载、Booth 买的、解压出来的文件夹）
做成一张张卡片，点卡片就打开素材所在的文件夹；还能记网盘链接、看哪个 Unity 工程用到了哪个素材、
同步 Booth 已购商品。所有数据都只存在你自己的电脑上。

【安装】
  安装版：双击「VRC素材库-安装-1.2.0.exe」，一路下一步。会在桌面和开始菜单放快捷方式。
          不需要管理员权限，装在 %LOCALAPPDATA%\Programs\VRC素材库。
  便携版：把「VRC素材库」文件夹解压到任意位置（别放 Program Files），双击里面的 VRC素材库.exe。

  第一次打开如果 Windows 提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
  （这是因为软件没有花钱买数字签名，不是病毒。）
  双击后打开软件自己的窗口（用 Windows 自带的 WebView2 显示界面），关掉窗口软件就退出。
  极少数没有 WebView2 的电脑会改用 Edge 的独立窗口；想在浏览器标签页里用，可以在设置里改。
  所有链接（Booth 商品页、订单页、网盘分享）都用默认浏览器打开。

【第一次打开】
  会让你选两样东西：
  1. 放素材的文件夹：比如 D:\BaiduNetdiskDownload、你自己整理素材的文件夹。能自动找到的会帮你勾上。
  2. Unity 工程（可以不选）：选了以后，卡片上会标出「在用：某某工程」。
  点「开始扫描」就好，第一次会慢一点（要读 unitypackage），之后每次打开都在后台自动更新。

【日常用法】
  点卡片                在资源管理器里打开素材所在位置
  右键 / 详情           改名称、分类、适配素体、标签、备注、封面，填网盘链接
  网盘按钮              复制提取码并打开分享链接（在详情里把百度网盘分享的整段文字粘进去，会自动拆出链接和提取码）
  Booth 按钮            打开 Booth 商品页；还没关联商品的素材会按名称在 Booth 上搜索
  名称下面的紫色小字    简体中文翻译（设置里可以关掉，详情里可以手改）
  左边栏                按分类、适配素体、Booth 已购、工程使用情况、网盘链接、来源文件夹筛选
  搜索框（按 / 聚焦）   搜名字、店铺、标签、路径、备注

【百度网盘】
  详情 →「网盘」里填分享链接，提取码没有就留空。保存后软件会读出分享里有哪些文件，按文件夹显示。
  只在网盘里、电脑上没有的素材：点右上角「＋ 网盘素材」，粘贴分享链接就能建一张卡片。
  左边栏「网盘 → 只在网盘里」可以只看这些。

【Booth 商品页】
  每个素材都能对上 Booth 商品：文件夹名里有商品编号的直接识别；没有的，详情 →「Booth 商品」里搜索，
  点「就是这个」关联。关联后会显示商品图、标签、商品说明（可以一键翻译成中文），没封面的素材也会补上封面。
  没有封面的素材，软件会自动按名称在 Booth 上搜一遍，只有名字和分类都对得上、而且只有一个候选时才自动关联，
  卡片详情里会标「按名称自动匹配的」，点「是这个」确认，或者「不是这个」换掉。

【Booth 已购】
  左边栏点「同步 Booth 已购」，会弹出一个单独的浏览器窗口：
  - 第一次需要在里面登录 Booth（pixiv 账号）。登录只保存在这个软件自己的窗口里，不碰你平时浏览器的账号。
  - 登录后会自动读取你的已购列表、收到的礼物和订单，读完窗口自动关闭。
  - 登录窗口用你的默认浏览器（支持 Chrome、Edge、Brave、Firefox 等；其他浏览器会改用 Edge）。
  - 如果 Google 登录提示「此浏览器可能不安全」，改用 pixiv ID / 邮箱密码登录。
  同步之后：
  - 本地已有的素材会标上「已购」，卡片上多一个「购买页」按钮，直接打开那笔订单（可以重新下载）。
  - 买了但本地还没有的，会出现在左边「已购，还没下载」里，点卡片打开下载页。
  - 本地素材和已购商品是按 Booth 商品编号、或者按下载文件名自动对上的。
  不想用了：设置 →「退出 Booth 登录」或「清空已购记录」。

【识别错了怎么办】（详情最下面「识别不对？」）
  拆成多个素材   —— 一个文件夹其实装了好几样东西
  隐藏           —— 留着但不显示（左栏底部勾「显示已隐藏的」可以找回）
  不再收录       —— 以后扫描都跳过这个位置
  拆分和不再收录可以在 设置 →「手动调整过的识别」里撤销

【设置】（右上角齿轮）
  素材文件夹、Unity 工程文件夹、Booth 代理（连不上 Booth 时填，例如 127.0.0.1:7890；留空用系统代理）、
  素体识别表、是否每次打开自动扫描、中文翻译、自动在 Booth 找封面、界面打开方式、桌面快捷方式。

【数据放在哪】
  安装版：%LOCALAPPDATA%\VRC素材库
  便携版：exe 旁边
  library.json   你填的所有内容（每次保存会留一份 library.json.bak）
  covers\        封面缓存（删了会重新下载）
  booth-profile\ Booth 登录窗口的数据（删了等于退出登录）
  卸载安装版时会问要不要一起删除数据。

【已知限制】
  rar / 7z 里面的内容不参与「工程使用」分析（zip 和 unitypackage 可以）
  「工程使用」按文件 GUID 比对，导入后被改过 GUID 的素材认不出来
  网盘分享只读得到文件名和大小，读不到图片；翻译用的是必应 / 谷歌的免费网页翻译，偶尔会翻得不准
  只支持 Windows 10 / 11
